## About

- 웹에서는 화면의 완성도와 자연스러운 사용자 흐름을 중요하게 생각합니다.
- API 연동, 상태 관리, 인증, 실시간 통신까지 프론트엔드 전반을 경험했습니다.
- 모바일과 백엔드를 함께 공부하며 클라이언트와 서버가 연결되는 구조를 이해하고 있습니다.
- 기능을 구현하는 것에서 끝내지 않고, 유지보수하기 편한 구조를 고민합니다.

## Featured Projects

### EUM Web

> 음성을 활용해 사용자를 매칭하고 소통할 수 있는 웹 서비스

`React` `TypeScript` `Vite` `TanStack Query` `Zustand` `Socket.io` `Tailwind CSS`

- 공통 버튼, 카드, 입력 요소를 재사용 가능한 컴포넌트로 구성했습니다.
- 온보딩부터 녹음, 매칭, 결과 확인까지 주요 사용자 흐름을 구현했습니다.
- TanStack Query와 Zustand를 활용해 서버 상태와 사용자 상태를 분리했습니다.
- 카카오 로그인과 배포 환경별 리다이렉트 문제를 해결했습니다.

[저장소 보기 →](https://github.com/UMC-Eum/UMC-Frontend)

<br />

### EUM Mobile

> 기존 웹 서비스를 Expo와 React Native 기반 모바일 앱으로 확장한 프로젝트

`React Native` `Expo` `TypeScript` `TanStack Query` `WebSocket`

- Apple, Kakao, 이메일 로그인 흐름을 구현하고 개선했습니다.
- 게시글 및 동호회 기능을 개발했습니다.
- 서버 상태를 캐시하고 필요한 시점에 갱신하도록 데이터 흐름을 구성했습니다.
- QA 과정에서 발견된 화면 전환과 상태 동기화 문제를 수정했습니다.

[저장소 보기 →](https://github.com/UMC-Eum/Frontend)

<br />

### DisplayU Backend

> 전시 관람 경험을 공유하는 커뮤니티 서비스의 백엔드 프로젝트

`Spring Boot` `Java` `JPA` `MySQL` `Flyway` `Swagger`

- 라운지 도메인의 게시글, 댓글, 답글 기능을 구현했습니다.
- 좋아요와 스크랩을 포함한 사용자 상호작용 API를 개발했습니다.
- 커서 기반 페이지네이션과 조회 전용 Query Repository를 구성했습니다.
- 요청값 검증과 도메인별 예외 처리를 적용했습니다.
- Flyway로 데이터베이스 변경 이력을 관리하고 Swagger로 API를 문서화했습니다.

[저장소 보기 →](https://github.com/UMC-DISPLAYU/Backend)

<br />
