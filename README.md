- 웹의 온보딩·음성 녹음·이상형 매칭·결과 화면을 구현하고, 이후 React Native와 Expo 기반 모바일 앱 개발 및 출시까지 담당
- Apple·Kakao·이메일 로그인과 인증 초기화·라우팅 흐름을 구축하고, 추천·마음·채팅·프로필·동호회 기능을 API와 연동
- Socket.io 기반 실시간 채팅과 S3를 활용한 사진·음성 전송, 메시지 읽음 및 시간 표시 구현
- TanStack Query로 서버 상태를 관리하고 Zustand로 사용자 입력 상태를 분리했으며, 사용자별 Query Key와 캐시 무효화를 적용해 계정·프로필 간 데이터 혼선 방지
- 배포 환경의 카카오 OAuth Redirect URI 오류와 만료되는 S3 이미지 URL 문제 등 로컬 환경에서 드러나지 않던 운영 이슈 해결
- App Store·Google Play 심사 대응과 3차례 QA를 진행하고, 운영 빌드의 테스트·목업 코드와 민감한 콘솔 로그를 정리해 양대 스토어 출시 완료
