## 🚀 Featured Projects

### 💻 EUM Web

> React와 TypeScript로 개발한 음성 기반 소셜 매칭 웹 서비스

**React · TypeScript · Vite · React Router · TanStack Query · Zustand · Tailwind CSS · Axios · Socket.io · Vercel**

- 버튼, 카드, 입력 요소 등 재사용 가능한 공통 컴포넌트 설계 및 구현
- 온보딩, 이상형 녹음·매칭·결과, 프로필 설정과 튜토리얼 화면 개발
- API 요청·응답 타입과 커스텀 훅을 분리하고 백엔드 DTO 변경에 맞춰 연동 구조 개선
- Zustand로 사용자 정보와 권한 상태를 관리하고 페이지 간 상태 흐름 구성
- TanStack Query의 폴링과 캐시를 활용한 알림 페이지·모달·전체 읽음 기능 구현
- 카카오 로그인과 리다이렉트 흐름을 구현하고 배포 환경별 URL 문제 해결
- Socket.io 기반 실시간 채팅, 사진·음성 파일 전송과 메시지 읽음·시간 처리 구현
- 화면 크기에 따른 UI 차이와 상태 동기화 문제를 수정하고 Vercel 배포 환경 구성
